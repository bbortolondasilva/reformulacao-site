# Reformulação de Site Empresarial

Projeto desenvolvido como atividade avaliativa da disciplina de **Programação Web I** do curso de **Sistemas de Informação**.

O objetivo foi realizar a reformulação de um site empresarial, aplicando conceitos de HTML, CSS e JavaScript para melhorar o layout, a organização das informações, a responsividade e a experiência do usuário.

## Demonstração

🔗 Site publicado: https://bbortolondasilva.github.io/reformulacao-site/

🔗 Site antigo:
https://softcontrolbrasil.com.br/

## Objetivos do projeto

- Reformular a interface de um site empresarial;
- Aplicar boas práticas de desenvolvimento web;
- Criar um layout responsivo para diferentes dispositivos;
- Melhorar a organização visual e a navegação do site;
- Utilizar HTML, CSS e JavaScript de forma integrada.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Email.js
- Git
- GitHub Pages

## Funcionalidades

- Layout responsivo;
- Menu de navegação;
- Seções organizadas para apresentação da empresa;
- Melhorias na identidade visual;
- Interface otimizada para desktop e dispositivos móveis.

## Como executar

1. Clone este repositório:

```bash
git clone https://github.com/bbortolondasilva/reformulacao-site.git
```

2. Abra a pasta do projeto.

3. Execute o arquivo `index.html` em um navegador.

Ou acesse diretamente a versão publicada:

https://bbortolondasilva.github.io/reformulacao-site/
